# gain 실행 결과 — 노출 gain 배치 / SNR 불변성 / fusion 검증 (2026-08-12, LOD_test)

## 0. 결론부터

이 모듈은 gain.md §1의 세 미측정 주장 중 두 개(업스트림 gain 배치,
정수연산 SNR 불변성)를 **이번에 처음 측정**했다 — 사용자가 명시적으로
지정한 범위(대화 스코프 #2)다.

1. **목표 A(업스트림 배치가 양자화 손실을 줄인다): 재현/확인됨.**
   48개 신호준위×채널 조합 중 **45/48**에서 업스트림(경로 A, 배포)의
   양자화 오차 표준편차가 다운스트림(경로 B, 대조군)보다 통계적으로
   유의하게 작았다(95% CI 비겹침). 나머지 3개(s=3072, 전 채널)는 두
   경로 모두 완전 포화(std=0)라 판별 불가능한 경계 케이스일 뿐, 반증이
   아니다.
2. **목표 B(정수 연산에서도 SNR 불변): 부분 성립, 예상대로 두 지점에서
   깨짐.** 64개 (gain배수×신호준위) 중 **51/64**가 ±1.5dB 이내로
   불변성을 유지했다. 깨지는 지점은 두 그룹이다 — (i) 클램프 포화
   구간(고신호×고gain, gain.md §3.2가 사전에 예상한 대로)과 (ii)
   **읽음 노이즈 바닥 근처의 저신호 구간(s=16~24)** — 이건 gain.md
   원 설계가 명시적으로 예상하지 않았던 추가 발견이다(§3.2).
3. **목표 C(fused vs separate gain): 완전 동일.** 0..4095 전수 비교에서
   3채널 모두 **0/4096 차이** — 12-bit·8-bit(탄 커브 대역 기준) 양쪽
   전부 LSB 편차 없음. 융합 곱셈이 반올림 오차를 전혀 만들지 않는다.
4. **목표 D(WB): AWB_report.md(2026-08-12, LOD_test)를 그대로 인용** —
   6-후보 스윕 spread(mAP@[.5:.95] 0.0010, mAP@50 0.0057)가 여전히
   BLC 레버 규모 대비 작아 "레버 아님" 결론 유지. 상세는
   `../AWB/AWB_report.md` 참고.
5. 노이즈 모델은 LOD_test ISO 6400 서브셋으로 **재캘리브레이션됐다**
   (`A_Q8=4114`, `B_DN2=803`, binning_report.md §2). 목표 A는 45/48,
   목표 C는 0/4096으로 배포 상수 실행과 동일하고, 목표 B만 52/64 →
   **51/64**로 한 점 달라졌다 — 2.0×/s=24가 1.4315dB → 1.5122dB로 ±1.5dB
   경계를 아슬하게 넘었다(§3).

## 1. 실행 조건

- 스크립트: `gain_sim.py --seed 0 --repeats 500`(목표 A/B 기본값; 목표 C는
  전수 비교라 반복 없음)
- 신호준위: binning_sim.py의 16점 리스트(16~3072 DN)를 그대로 재사용
  (`from binning_sim import SIGNAL_LEVELS`)
- 노이즈 모델: `A_Q8=4114`, `B_DN2=803` (LOD_test ISO 6400 재캘리브레이션,
  binning_report.md §2 — `--a-q8 4114 --b-dn2 803`으로 전달)
- gain 배수(목표 B): 0.5×/1.0×/2.0×/4.0× (Q8 클램프 [64,1024] 커버)

### 실행 중 발견한 버그: blc_sim.py와 동일한 경로 계산 어긋남

`gain_sim.py`도 blc_sim.py와 똑같은 `parents[1]` off-by-one 버그를
갖고 있었다(디렉터리 재편 이전 평평한 구조를 가정한 경로 계산) —
`parents[2]`로 고치고 `sim/binning/` 경로를 추가해 `binning_sim`
import(`CHANNEL_STYLE, SIGNAL_LEVELS, variance`)가 다시 되게 했다.
상세 경위는 `../blc/blc_report.md` §1 참고(같은 원인, 같은 수정).

## 2. 목표 A — 업스트림 vs 다운스트림 gain 배치

경로 A(배포): `correct_channel()`(BLC→gain, 12-bit 도메인) → `>>4`.
경로 B(대조군): BLC(12-bit) → `>>4`(8-bit로 조기 절단) → gain(8-bit
도메인에서 적용, 클램프).

| 신호준위 | 채널 | std_upstream | std_downstream | 판정 |
|---:|---|---:|---:|---|
| 16 | R/G/B | 0.25~0.28 | 0.51~0.72 | PASS (전 채널) |
| 128 | R/G/B | 0.30~0.31 | 0.60~0.80 | PASS |
| 512 | R/G/B | 0.28~0.30 | 0.60~0.76 | PASS |
| 1024 | R/G/B | 0.28~0.29 | 0.57~0.75 | PASS |
| 2048 | R | 0.156 | 0.391 | PASS |
| 2048 | B | 0.101 | 0.257 | PASS |
| 3072 | R/G/B | 0.000 | 0.000 | **판별불가**(완전 포화) |

45/48 지점에서 업스트림(경로 A)의 양자화 오차 표준편차가 다운스트림의
약 절반 수준으로, 전 구간에서 일관되게 작다 — gain.md §2.2가 인용한
"저조도+고gain에서 양자화 분산이 gain 배수로 벌어진다"는 주장을
뒷받침한다. s=3072에서의 3개 FAIL은 반증이 아니라 두 경로 모두 8-bit
출력이 이미 255(포화)에 고정돼 분산 자체가 0이 되는 경계효과다 — 이
신호준위에서는애초에 양자화 손실을 비교할 여지가 없다.

## 3. 목표 B — 정수 연산에서의 SNR 불변성

51/64 지점이 ±1.5dB 이내. 깨지는 13개 지점:

| gain배수 | 신호준위 | delta_dB | clip_rate | 메커니즘 |
|---|---:|---:|---:|---|
| 0.5× | 16 | +2.65 | 0% | 저신호 반올림 |
| 1.0× | 16 | +3.14 | 0% | 저신호 반올림 |
| 1.0× | 24 | +2.19 | 0% | 저신호 반올림 |
| 2.0× | 16 | +2.96 | 0% | 저신호 반올림 |
| 2.0× | 24 | +1.51 | 0% | 저신호 반올림 — **신규 상수에서 새로 경계 초과**(배포 상수: +1.43, PASS) |
| 4.0× | 16 | +3.31 | 0% | 저신호 반올림 |
| 4.0× | 24 | +2.12 | 0% | 저신호 반올림 |
| 2.0× | 2048 | +4.44 | 48.6% | 클램프 포화 |
| 4.0× | 1024 | +4.50 | 48.4% | 클램프 포화 |
| 2.0× | 3072 | −inf | 100% | 완전 포화 |
| 4.0× | 1536/2048/3072 | −inf | 100% | 완전 포화 |

**두 가지 서로 다른 파괴 메커니즘**을 확인했다:

1. **고신호×고gain 클램프 포화** — gain.md §3.2가 사전에 명시적으로
   예상한 그대로다. gain을 곱한 뒤 `RAW12_MAX`(4095)에서 잘리면
   출력 분산이 줄어(또는 완전 포화 시 0으로 사라져) SNR이 왜곡된다.
2. **저신호(s=16~24) 반올림** — gain.md 원 설계가 명시적으로 예상하지
   않았던 지점이다. gain 배수와 무관하게(0.5×/1.0×/2.0×/4.0× 전부에서
   나타남) 신호가 read-noise 바닥 근처일 때 `(v*gain_q8)>>8` 정수
   절단의 상대적 영향이 커져, "gain은 SNR을 바꾸지 않는다"는 이론이
   저신호 구간에서도 무너진다는 걸 이번에 처음 정량 기록했다 — gain.md
   §4에 추가할 만한 새 한계다.

## 4. 목표 C — fused vs separate gain, 전수 비교(0..4095)

| 채널 | 12-bit 차이 | 8-bit(탄 커브 대역 기준) 차이 |
|---|---|---|
| R | 0/4096 | 0/4096 |
| G | 0/4096 | 0/4096 |
| B | 0/4096 | 0/4096 |

전수 비교(0~4095, 반복 없음) 결과 **완전히 동일**하다 — 융합 곱셈
(`gain_q8 = (EXPOSURE_GAIN_Q8*wb_q8)>>8`, `>>8` 1회)이 분리 적용
(`>>8` 2회)과 단 1 LSB의 차이도 만들지 않는다. 이미 골든 벡터로
bit-exact 검증되던 사실(gain.md §2.3)을, 이번엔 전체 입력 범위에 대해
직접 수치로도 재확인했다.

## 6. 알려진 한계 (gain.md §4에 추가)

- 목표 A/B는 검출 mAP 효과를 다루지 않는다 — gain.md §4가 이미 명시한
  대로, 통계적으로 유의한 양자화/SNR 차이가 발견됐다고 해서 "gain 배치를
  바꿔야 한다"는 결론으로 이어지지 않는다.
- 목표 B의 저신호 반올림 파괴(§3의 새 발견)는 예상 밖이었다 — 클램프
  경계만 예상했던 gain.md §3.2 대비 범위가 넓어졌다. 실무적으로는 이
  파이프라인이 저신호 구간에서 이미 BLC 클리핑(§blc_report.md)의 영향을
  더 크게 받으므로, 이 저신호 SNR 불변성 붕괴가 별도의 실질적 위험을
  더하는지는 이 실험 범위 밖이다.
- 노이즈 모델은 LOD_test ISO 6400 서브셋으로 재캘리브레이션했다(binning_report.md
  §2와 동일 근거).
