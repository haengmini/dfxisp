# Gain — 노출 gain / WB 시뮬레이션 방법론

## 1. 시뮬레이션 목표

`lowlight_isp.md`가 stage (3)에 대해 배포한 세 가지 주장:

1. **Upstream 배치(§2.3)**: "gain은 SNR을 바꾸지 못하지만(신호·노이즈 동배율),
   저조도+고gain에서 양자화 분산이 gain 배수로 벌어지므로 비트폭이 넓은
   Bayer 도메인에서, `>>4` 이전에 적용한다."
2. **gain 융합(§2.3)**: 노출 gain(2.0×)과 채널별 WB를 하나의 Q8 곱셈으로
   융합한다(`correct_channel()`의 `gain_q8 = (EXPOSURE_GAIN_Q8 * wb_q8) >> 8`).
3. **적응 AWB 미채택(§2.4)**: "WB는 3회 독립 검증에서 레버가 아님이 확정됐다
   ... 전 범위 mAP spread 0.0020 = BLC 레버 0.0876의 1/44."

**이 문서가 검증할 것**: 이 세 주장 각각의 재현 가능성을 따로 판정하고,
없는 부분을 새로 설계한다. WB(③)는 이미 완결된 검증이 있으므로(§2 참고,
재실험하지 않음) 이 문서가 새로 채워야 할 것은 **노출 gain의 배치(Upstream
vs Downstream)와 정수 연산에서의 SNR 불변성**이다(§3의 목표 A/B/C).

## 2. 시뮬레이션 이론

### 2.1 gain과 SNR 불변성

gain은 SNR을 바꾸지 않는다는 것은 이론적으로 자명하다 — 신호와 노이즈가
같은 배수로 스케일되므로 SNR = signal/noise 비율이 불변이다
(`lowlight-feature-principles-2026-07-05.md` §4.3 인용). 다만 이 파이프라인의
실제 정수 연산(Q8 고정소수점, 클램프, `>>8` 절단)에서도 이 불변성이
성립하는지는 확인된 적 없음 — 정수 반올림과 클램프 경계가 이 불변성을
깨뜨릴 수 있다.

### 2.2 양자화 분산과 gain 배치

EMVA1288 `σ²_total = σ²_read + σ²_quant + K·μ` 형태의 공식과 Nakamura(2005)/
Chen(CVPR'18, SID) 인용: 저조도+고gain에서 양자화 분산이 gain 배수로 벌어지므로,
비트폭이 넓은 Bayer 도메인에서(`>>4` 절단 이전에) gain을 적용해야 손실이
작다는 주장이다. 인용 근거만 있고, 이 파이프라인의 실제 상수
(`EXPOSURE_GAIN_Q8=512`, `>>4` 절단)로 계산되거나 시뮬레이션된 적은 없다.

### 2.3 gain 융합

노출 gain(2.0×)과 채널별 WB를 하나의 Q8 곱셈으로 융합한다
(`correct_channel()`의 `gain_q8 = (EXPOSURE_GAIN_Q8 * wb_q8) >> 8`). 구현
자체는 정본이고 골든 벡터로 bit-exact 검증됨(`make lowlight-isp-verify`).
다만 "융합이 분리 적용과 수치적으로 동일한가"(반올림 오차 유무)는 별도로
확인된 적이 없다.

### 2.4 기존 근거와 재현 가능성

| 주장 | 위치 | 재현 가능성 |
|---|---|---|
| ③ WB는 레버가 아니다 | `isppipeline/sw/sim/AWB.md`(원 근거: `isppipeline/hls/results/lowlight-wb-mode-split-2026-08-03.md`) | ✅ **네 모듈 중 유일하게 완전한 실측 방법론 — 이제 sw/sim/ 계열로 독립 정리됨.** post-BLC 채널 통계 실측(SonyNOD 저조도 vs PASCALRAW 밝음, 배포 WB가 gray-world 대비 B gain 0.50×로 부족함을 정량 확인) → `--wb-lowlight` 오버라이드로 실제 mAP 스윕(6개 후보, `data/split_nod` n=321, YOLOv8n) → 전 범위 spread 0.0020 vs BLC 레버 0.0876(§3.3) → 채널 분리 시 초가산적 패턴(R만 −0.05%, B만 −0.19%, 둘다 +0.61%)이 물리적 메커니즘 부재를 시사한다는 반증 논리(§3.2)까지 갖춘 모범 사례. 이 문서를 §3의 템플릿으로 그대로 재사용한다. |
| ① 업스트림 배치(양자화 분산 주장) | `lowlight_isp.md` §2.3, `lowlight-feature-principles-2026-07-05.md` §4.3 | **인용 근거만, 측정 없음.** §2.2의 공식과 인용은 있지만, "저조도+고gain에서 양자화 분산이 gain 배수로 벌어진다"를 이 파이프라인의 실제 상수로 계산하거나 시뮬레이션한 적이 없다. |
| ② gain 융합의 정확성 | `gen_lowlight_isp_golden.py`의 `correct_channel()` | ✅ 구현 자체는 정본이고 골든 벡터로 bit-exact 검증됨(`make lowlight-isp-verify`). 다만 "융합이 분리 적용과 수치적으로 동일한가"(반올림 오차 유무)는 별도로 확인된 적이 없다 — §3.3에서 다룬다. |
| "gain은 SNR을 바꾸지 않는다"는 일반 주장 | `lowlight-feature-principles-2026-07-05.md` §4.3 (인용) | §2.1 참고 — 이론적으로 자명하나 이 파이프라인의 실제 정수 연산에서의 성립 여부는 확인된 적 없음. |

**요약**: WB(적응 여부)는 이미 잘 검증돼 있다. 이 문서가 새로 채워야 할 것은
**노출 gain의 배치(업스트림 vs 다운스트림)와 정수 연산에서의 SNR 불변성**이다.

## 3. 시뮬레이션 방법 (구현 완료 — gain_sim.py, gain_report.md 참고)

### 3.1 목표 A — 업스트림 배치가 양자화 손실을 실제로 줄이는가

`lowlight-wb-mode-split-2026-08-03.md`를 템플릿으로 삼아 같은 구조
(실측 → 통계적 반증 시도 → mAP 스윕)를 따른다.

**방법**:
1. `binning.md` §2.2/§3.1의 노이즈 모델로 binned 12-bit 신호를 합성.
2. **경로 A(현재 구현, 업스트림)**: `correct_channel()`을 그대로 호출 —
   BLC → gain(2.0××WB, 12비트 도메인) → (시뮬레이션에서는 `ccm_channel()`
   생략하고 바로) `>>4` 양자화.
3. **경로 B(대조군, 다운스트림)**: BLC까지는 동일하게 적용한 뒤, gain을
   적용하지 **않은 채** `>>4` 양자화를 먼저 하고, 그 8비트 값에 gain을 곱한
   뒤 다시 클램프 — "gain을 좁은 비트폭 도메인에서 적용"하는 조작.
4. 두 경로 모두 참값(gain 적용 전 이상적 실수 연산 결과)과 비교해 **양자화
   오차의 표준편차**를 신호준위별로 측정.

**판정 기준**: 경로 A의 양자화 오차 표준편차가 경로 B보다 유의하게
작아야 한다(§3.1의 신호준위 스윕 재사용, 각 점 500회 반복, 95% CI 비교).
차이가 없거나 반대 방향이면 §1의 ① 주장은 이 실험 범위 내에서 반증된
것으로 기록한다(binning.md/blc.md와 같은 정직한 기록 원칙).

### 3.2 목표 B — 정수 연산에서도 SNR이 불변인가

같은 합성 신호에 gain 배수(0.5×, 1.0×, 2.0×, 4.0×, Q8 클램프 범위
[64,1024] 전체를 커버)를 적용한 뒤, `correct_channel()`과 동일한 정수
경로(곱셈 → `>>8` → 클램프)로 처리한 SNR을 측정하고 이론값(불변, §2.1)과
비교한다. 클램프 경계(Q8 [64,1024])에 걸리는 극단 신호준위에서는 불변성이
깨질 것으로 **예상**하고, 그 깨지는 지점을 정량적으로 기록하는 것 자체가
목표다(파괴적 결과가 나와도 지우지 말 것 — `lowlight-wb-mode-split` §"Audience"
관례).

### 3.3 목표 C — gain 융합이 분리 적용과 수치적으로 동일한가

`correct_channel()`의 `gain_q8 = (EXPOSURE_GAIN_Q8 * wb_q8) >> 8`(융합,
정수 반올림 1회)과, `>>8`을 두 번 나눠 적용하는 분리 버전(노출 gain 적용 →
`>>8` → WB 적용 → `>>8`, 반올림 2회)을 8비트 출력까지 전체 신호준위(0~4095)에
대해 전수 비교한다. 이건 통계 시뮬레이션이 아니라 **전수 대조**이므로
반복이 필요 없다 — 차이가 나는 신호준위의 개수와 최대 편차(LSB 단위)를
보고한다.

### 3.4 목표 D — WB(§2.4)는 재실험하지 않는다

`lowlight-wb-mode-split-2026-08-03.md`가 이미 세 번째 독립 검증까지 마치고
"재실험 불필요"로 결론 내렸다(§0). **이 재현 방법론은 `AWB.md`가 sw/sim/
계열 형식으로 독립 정리했으므로**, 이 문서는 새 시뮬레이션을 설계하는 대신
`AWB.md`를 인용하는 것으로 목표 D를 채운다 — 중복 실험으로 자원을 쓰지
않는다. WB 결론을 다시 재현하거나 새 후보로 스윕하고 싶다면 이 문서가
아니라 `AWB.md` §3(재현 절차)을 실행한다.

## 4. 알려진 한계

- 목표 A/B는 `>>4`/`>>8` 정수 절단이 지배하는 저비트 영역에서의 효과를
  다룬다. 실제 검출 mAP에 이 차이가 반영되는지는 §2의 WB 사례(물리적 진단은
  사실이었지만 검출은 무반응)에서 보듯 **자동으로 보장되지 않는다** —
  이 시뮬레이션이 통계적으로 유의한 차이를 찾더라도, mAP 스윕으로
  별도 확인하기 전까지는 "배치를 바꿔야 한다"는 결론을 내리지 않는다.
- 목표 C는 현재 구현이 올바른지 확인하는 회귀 테스트 성격이며, 설계
  근거를 흔들 가능성은 낮다(이미 골든 벡터로 bit-exact 검증되고 있으므로).
  그럼에도 "융합이 왜 안전한가"를 문서화하는 데는 값어치가 있다.
