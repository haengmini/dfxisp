# 히스토그램 LRT 체커 실험 결과 (강화전략 #2, 2026-07-09)

**작성:** 2026-07-09 KST · **브랜치:** `exp/principled-checker-rm-2026-07-05`

> 사전 등록된 수용 기준(strategy #2): held-out J ≥ C1 + 0.04 = **0.887**.
> 결과: **3개 변형 모두 미달(최고 0.835) → 기각.** coarse 변형 재시도까지
> 포함해 기각 확정. 이는 C4(2-feature)를 기각시킨 것과 같은 정직성 기준의
> 결과이며, dark16 단일 통계량이 이 데이터·라벨에서 히스토그램의 선형
> 추출 가능 정보를 사실상 소진하고 있음을 실증한다.

## 1. 설계 요약

- **모델:** `score = Σ_b w_b·ĥ_b + b₀`, ĥ = 256-bin(raw>>8) 정규화
  히스토그램(HW가 이미 1-pass로 계산하는 것과 동일). dark16은 w=1[b<16]인
  특수해이므로 본 모델은 dark-ratio 계열의 엄밀한 상위집합.
- **정규화:** ridge + 2차차분 평활(OOD 방어). 단조성은 강제 대신 사후 검사.
- **변형 3개:** LRT-256(full), LRT-log16(반옥타브 16-bin), LRT-log8(옥타브
  8-bin) — coarse가 strategy의 "기각 전 재시도" 조항.
- **정직성:** outer 5-fold(seed 0, `kfold_cv`와 동일 분할) × inner 3-fold
  nested-CV로 (λ_ridge, λ_smooth) 선택. 가중치·임계 모두 train에서만 적합.
  int8 양자화 쌍둥이를 fold별 동시 평가(HW = 256-entry ROM + MAC 1개).
- **구현:** `tools/checker_lrt.py` (numpy 단독, IRLS/뉴턴). 히스토그램
  덤프는 `results/scratch_frame_hist.npz` (1150×256, int64).

## 2. 결과 (전부 held-out)

**기준선(동일 fold, seed 0):** C1 고정 `dark16>0.62` recall 0.936 / FT
0.089 / **J 0.847** / R 0.00531 (적합 없음→정직). dark16 J-fit 5-fold CV는
J 0.838(적합 통계량끼리의 공정 비교선).

| 변형 | oof AUC | CV recall | CV FT | CV J | CV R | int8 J | w 단조율 |
|---|---|---|---|---|---|---|---|
| LRT-256 (ridge+smooth) | 0.9667 | 0.926±0.019 | 0.103±0.041 | 0.824 | 0.00611 | 0.829 | 0.49 |
| LRT-log16 | 0.9761 | 0.929±0.020 | 0.100±0.044 | 0.829 | 0.00588 | 0.831 | 0.53 |
| **LRT-log8 (최고)** | **0.9771** | 0.927±0.009 | 0.092±0.049 | **0.835** | 0.00587 | 0.833 | 0.71 |

- **모든 변형이 C1(0.847)은 물론 dark16 CV(0.838)에도 미달.** oof AUC
  최고 0.9771도 dark16 단독(0.9766)과 동률 — 순위지표 차원에서도 추가
  정보가 없다.
- 자유도가 큰 LRT-256이 log8보다 나쁘다(0.824 < 0.835): n=920 train에서
  256차원은 평활 정규화로도 과적합. coarse가 나은 것 자체가 "히스토그램에
  더 짜낼 선형 정보가 없다"는 신호.
- int8 양자화 손실은 ΔJ ≤ 0.005로 무시 가능(HW 실현성은 문제 아님).

## 3. 원인: 학습된 LRT가 dark-ratio를 재발견한다

LRT-log8 fold-평균 가중치(옥타브 bin 0..7 = raw8 [0,2),[2,4),...,[128,256)):

```
w = +1.02 +0.75 +0.82 -0.00 -0.20 -0.73 -0.88 -0.79
```

하위 3 bin(raw8 < 8) 양(+), bin3(8~16) 0, 상위 음(−) — **데이터가 고른
최적 선형 판별이 곧 "저 bin 질량 vs 고 bin 질량", 즉 dark-ratio 형태**다.
경계도 dark16(≈bin 0–3)과 일치. 원리 문서(theory §1.3)의 data-processing
부등식은 "히스토그램 LRT ≥ dark-ratio"를 보장하지만, 이 데이터에서는
등호가 (표본 한계 내에서) 성립함을 실증한 것.

**잔존오차 회수(oof 기준, 정직):** C1 오류 88장(miss 37/FT 51) 중 LRT가
회수한 것은 miss 5 + FT 10 = 15장뿐이고 **새 오류 16장을 만들어 순이득
≈ 0**. 양쪽 다 틀리는 **공통 병목 78장**이 그대로 남는다 — 예: dark16
0.65~0.78의 진짜 어두운 COCO 프레임들(라벨상 NORMAL). 이는 analysis
§3의 "잔존오차는 라벨 정의 아티팩트" 가설과 정합.

## 4. 판정 및 다음 액션

**기각(현행 라벨 기준).** 사전 등록 기준(J ≥ 0.887) 미달이 fold-분산
논쟁의 여지 없이 명확(-0.012~-0.023). coarse 재시도 조항까지 소진.

**단, 조건부 재평가 1회를 남긴다:** 기각의 병목이 모델이 아니라 **라벨**
(공통 78장)이므로, #4 오라클 라벨 재정의 후 같은 인프라(`checker_lrt.py`,
npz 재사용)로 1회 재실행한다. 오라클 라벨에서 병목이 don't-care 밴드로
빠지면 LRT와 dark16의 순위가 바뀔 여지는 낮지만, "dark16 충분" 결론을
오라클 기준으로 재확인하는 비용이 사실상 0이다.

**논문 관점의 수확:** (i) dark16 채택의 근거가 "그리드에서 최고"에서
"**학습형 상위집합 모델이 같은 해로 수렴, 잔존오차는 정보 부족이 아니라
라벨 경계**"로 격상. (ii) 체커 강화 자원은 #4(오라클 라벨)와 #1(적응 τ)에
집중해야 한다는 전략 문서의 우선순위가 실험으로 뒷받침됨.
