# 저조도 WB 모드별 분리 — 실 RAW 최종 판정 (2026-08-03)

## 0. 결론부터

**저조도 WB를 모드별로 분리하지 않는다.** 배포된 공유 WB(`AWB_R/G/B = 286/256/307`)를
그대로 유지한다.

배포 WB가 저조도 데이터에 **객관적으로 잘못 맞춰져 있다는 진단은 사실로 확인**됐다
(§2 — SonyNOD가 필요로 하는 B 게인의 0.50배). 그러나 그것을 고쳐도 **검출 성능은
움직이지 않는다**(§3). 전 파라미터 범위(WB 완전 제거 ~ 2배 과보정)의 mAP spread가
**0.0020**으로, BLC 레버(0.0876)의 **1/44**에 불과하고, 채널 분리 실험이 효과 자체를
반증했다(§3.2).

이로써 WB는 **세 번(07-02 combined / 07-03 분리 / 08-03 실 RAW) 검증되어 모두
"레버가 아니다"로 수렴**했다. 재실험 불필요.

---

## 1. 왜 세 번째로 다시 검증했나 — 앞선 두 실험의 구조적 결함

07-03 분리 ablation(`phase0-2-execution-2026-07-03.md` §1.1/1.2)은 이미
"진짜 범인은 WB가 아니라 BLC"라고 결론냈다(`ll_wb_skip`으로 WB를 완전히 꺼도
−0.5%). 그러나 그 측정에는 두 가지 결함이 있어 **현재 조건에 그대로 적용할 수
없다고 판단**했다:

1. **pseudo-RAW에서 측정.** ExDark/COCO의 pseudo-RAW는 JPEG 역변환이라
   **이미 카메라 AWB를 거친 데이터**다. 이미 화이트밸런스가 맞은 데이터에 WB
   게인을 걸거나 빼도 거의 안 움직이는 것은 당연하며, 실제 조명 색온도가 살아있는
   real 센서 RAW에 대한 답이 아니다.
2. **BLC=16에서 측정.** WB는 BLC **이후**에 적용된다. BLC=16(12-bit 4096 감산)이면
   저조도 픽셀 대부분이 0으로 클리핑되고, 0에 어떤 게인을 곱해도 0이다 — 즉
   "이미 파괴된 신호에서 WB가 의미 있나"를 물은 셈. 현재 배포값은 BLC=2다.
3. (부차) 표본이 n=31(ExDark)/39(COCO)로 작고, 07-08 canonical 파이프라인 이전
   버전(float gamma)에서 측정됐다.

**따라서 실 RAW(SonyNOD 321) + BLC=2 + canonical 파이프라인에서 재검증했다.**

## 2. 사전 측정 — 진단은 사실이었다 (GPU 불필요)

WB가 적용되는 바로 그 도메인(bin-demosaic → BLC 감산 직후, RAW16)에서 정본
데이터셋의 채널 통계를 실측했다(`tools/` 외부 임시 스크립트, 픽셀 stride 4,
전 프레임 321장씩).

| 항목 | SonyNOD (저조도) | PASCALRAW (밝음) |
|---|---:|---:|
| post-BLC 채널 평균 R / G / B | 795.5 / 1350.4 / 561.5 | 2953.4 / 6210.5 / 4750.8 |
| 채널비 R/G | 0.589 | 0.476 |
| 채널비 **B/G** | **0.416** | **0.765** |
| gray-world WB (Q8, G=256) | R 435 / B **616** | R 538 / B **335** |
| **배포값(286/256/307) / gray-world** | R 0.66× / **B 0.50×** | R 0.53× / **B 0.92×** |
| BLC로 0 클리핑 [%] (R/G/B) | 64.2 / 52.0 / **72.7** | 19.7 / 7.8 / 12.8 |
| 포화(255) [%] (R/G/B) | 0.41 / 0.63 / 0.31 | 0.71 / 2.13 / 1.85 |

**진단 확인:** 배포된 B 게인(307)은 PASCAL이 요구하는 값(335)의 **0.92배로 거의
정확**한 반면, SonyNOD가 요구하는 값(616)의 **0.50배**다. 즉 배포 WB는 사실상
**밝은 장면용 캘리브레이션**이며 저조도에는 청색 보정이 절반만 걸린다. 두 조건 간
요구 게인 격차는 **B에서 1.84배**.

**결함 2 확인:** BLC=2인 지금도 저조도 픽셀의 **52~73%가 0으로 클리핑**된다.
BLC=16이던 07-03 당시에는 사실상 전멸 상태였을 것이므로, 그때 WB가 무반응이었던
것은 설명된다.

**부수 성과:** `design-limitations-2026-07-03.md` §1.4가 "최신 파라미터로 재측정
안 됨"으로 남겨둔 **포화율 공백을 메웠다** — 당시 우려된 11.25% 과포화는 현
파라미터에서 재현되지 않는다(최대 2.13%).

## 3. mAP 실측 — 그러나 검출은 반응하지 않았다

조건: SonyNOD(`lod_split`, n=321), `lowlight` arm 단독, BLC=2 고정, YOLOv8n,
imgsz=640. `normal` 경로는 `--wb-lowlight`의 영향을 받지 않는다.

### 3.1 전체 결과

| 후보 | WB (R:G:B) | mAP@[.5:.95] | Δ vs 배포 | mAP@50 | Δ vs 배포 |
|---|---|---:|---:|---:|---:|
| WB 완전 off | 256:256:256 | 0.2134 | −0.33% | 0.3782 | −0.76% |
| **배포값(공유)** | **286:256:307** | **0.2141** | (기준) | **0.3811** | (기준) |
| R만 이동 | 360:256:307 | 0.2140 | **−0.05%** | 0.3813 | +0.05% |
| B만 이동 | 286:256:460 | 0.2137 | **−0.19%** | 0.3820 | +0.24% |
| R+B 중간 | 360:256:460 | 0.2154 | +0.61% | 0.3825 | +0.37% |
| R+B gray-world | 435:256:616 | 0.2143 | +0.09% | 0.3830 | +0.50% |

**하네스 회귀 검증:** 배포값 control이 07-15 정본(`lod-pascal-isp-simulation-
2026-07-15.md` §6의 LOD/BLC=2/lowlight = **0.2140 / 0.3810**)을 **0.2141 / 0.3811**로
재현했다 — 이번 `--wb-lowlight` 추가가 기존 경로를 바꾸지 않았음을 확인
(잔차 0.0001은 GPU 추론 비결정성 수준).

### 3.2 채널 분리 실험이 효과를 반증한다 (핵심)

- **R만** 이동: −0.05%
- **B만** 이동: −0.19%
- **둘 다** 이동: **+0.61%**

각 채널 단독으로는 손해인데 합치면 이득이라는 **초가산적 패턴은 물리적 메커니즘이
없다.** WB 보정이 실제 효과라면, 2배나 부족한 것으로 측정된 B를 단독으로 고쳤을 때
이득의 대부분이 나와야 하는데 오히려 −0.19%다. 이는 mAP(IoU 0.5:0.95 평균)의
임계값 기반 비평활성에서 오는 **jitter**로 보는 것이 타당하다.

### 3.3 규모 비교

```text
WB 전 범위 spread (off ~ 2배 과보정) : 0.2134 ~ 0.2154 = 0.0020
BLC 레버 (07-03 실측, 16 -> 8)       : 0.0619 -> 0.1495 = 0.0876   (44배)
```

## 4. 해석 — 색이 틀린 것과 검출이 나쁜 것은 별개다

배포 WB가 저조도 색을 잘못 보정하는 것은 사실이지만(§2), 검출기는 이에 반응하지
않는다. 이유:

1. **채널별 전역 게인은 대각 선형변환**이라 에지·형태·공간 구조를 움직이지 않고
   채널 크기만 재조정한다. 검출은 공간 구조에 의존한다.
2. COCO 사전학습 검출기는 **다양한 조명에서 학습**되어 전역 색 캐스트에 이미
   상당히 불변이다.
3. WB는 **BLC 클리핑 이후**에 적용되므로, 이미 0이 된 저조도 픽셀
   52~73%는 어떤 게인에도 0으로 남는다 — WB가 작용할 수 있는 여지 자체가 제한적.
4. 이후 **gamma 2.0(sqrt)** 이 남은 차이를 추가로 압축한다.

## 5. 배포 결정

**배포하지 않는다.** `AWB_R/G/B = 286/256/307` 공유 유지, HW 상수 변경 없음,
csynth/DFX 재실행 불필요, golden 재생성 불필요.

근거: (a) §3.2가 효과를 반증했고, (b) 액면가 +0.61%조차 이 프로젝트의 판단 기준인
**arm 순서**(`lowlight` vs `normal` vs `adaptive`)를 바꾸지 못한다.

### 주목할 패턴 (논문에 쓸 만함)

모드별로 분리할 후보였던 **두 색보정 상수가 모두 "분리 불필요"로 수렴**했다:

| 상수 | 분리 시도 | 결과 |
|---|---|---|
| BLC | 07-03 완화(256→128) 배포 → 07-20 실 RAW 재보정 | **양쪽 모두 2가 최적** — 모드별 차등 불필요 |
| WB | 08-03 (이 문서) | **분리해도 mAP 무변** — 모드별 차등 불필요 |

즉 normal/low-light 두 모드의 실질적 차이는 **색보정 상수가 아니라 구조**
(2×2 binning, 노출 게인 1.25× vs 2.0×)에 있다. baseline core의 색보정 파라미터는
조도 조건에 대해 견고하다.

> **주의:** 이것은 "모듈을 독립적으로 분리할 이유가 없다"는 뜻이 **아니다.**
> RP 경계·순서 자유도·문서-구현 불일치는 별개 논점이며
> `design-limitations-2026-07-03.md` §4.3과 `STRATEGY.md` 열린 질문 #4를 참조.
> 이 문서가 기각한 것은 **WB 상수의 모드별 재튜닝**뿐이다.

## 7. 후속 후보 (이 문서 범위 밖, 미착수)

- **BLC=0 미검증:** 정본 캠페인(07-15)은 `--blc-offsets 16,1,2`만 돌렸고 **0은
  포함되지 않았다.** §2에서 저조도 픽셀의 52~73%가 BLC=2에서도 0으로 클리핑되는
  것이 확인됐으므로, BLC=0이 근-흑색 픽셀을 살려 이득을 줄 가능성은 열려 있다
  (8-bit 값 1~2는 gamma 2.0 후 15~22로 올라온다). 비용은 이 문서의 실험과 동일.
- **교차 모델:** 위 결론은 YOLOv8n 기준. 효과 크기가 노이즈 수준이라 모델을
  바꿔 뒤집힐 가능성은 낮으나, 진행 중인 YOLOv8s 교차검증에서 함께 확인 가능.
