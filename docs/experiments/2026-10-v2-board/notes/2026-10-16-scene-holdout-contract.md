# DFXISP 새 장면 holdout 구성 계약

## 현재 상태
평가 계약과 미사용 ID 목록 작성 완료. 독립 장면 데이터 확보 및 중복 감사는 미완료다. 이 문서는 독립 시험셋 생성 완료를 뜻하지 않는다.

## 로컬 후보 감사
Sony 라벨 3,213개 고유 ID에서 기존 학습·검증·시험 519개와 신규 선택 1,200개 전체를 보수적으로 제외했다. 미사용 ID 1,494개 중 사용 ID와 번호 거리가 3을 넘는 것은 15개, 20을 넘는 것은 0개였다. 미사용 ID라도 같은 장소·세션일 수 있으므로 독립 장면으로 간주하지 않는다. 번호 인접성은 선별 보조 정보일 뿐 장면 판정 기준이 아니다. RAW 해시·지각 중복·촬영 메타데이터는 아직 확인하지 않았다.

## 데이터 수용 게이트
촬영 세션과 장소를 그룹으로 지정한다. 기존 train, calibration, 개발 val, 회고적 test와 같은 장면·근접 촬영 그룹은 제외한다. 원래 프로젝트 검출모델의 학습 이력도 포함해 감사한다. 이력을 알 수 없는 자료는 독립성 미확인으로 따로 표시하고 최종 holdout에 자동 편입하지 않는다.

각 원본에 source_id, source_path, capture_session, location_group, scene_id, source_split, raw_sha256, label_sha256, sensor, CFA, black_level, white_level, exposure 정보를 기록한다. 실제로 없는 메타데이터는 추정해 채우지 않는다. RAW 원본 SHA와 공통 변환 뒤 픽셀 해시를 기존 자료와 대조하고, 지각 근접 후보는 원본을 눈으로 확인한다. 해시가 다르다는 사실만으로 독립이라 하지 않는다.

야간과 주간은 각각 RAW와 person/car/bicycle 라벨이 필요하다. 주간 JPG replay는 RAW ISP 효과를 검증하는 주간 holdout의 대체재가 아니다. 새 센서 RAW를 기존 RGGB 계약으로 옮길 때 센서·블랙레벨·기하 변환 차이를 기록한다. 신규 다운로드 전에 크기와 저장 공간을 확인하고 원본·기존 결과를 삭제하지 않는다. Drive는 읽기 전용이며 결과 업로드는 하지 않는다.

## 평가 전 동결
모델은 기존/새 YOLO 3시드 및 SE 수정 기준선/새 SSD 3시드를 사용하고 정확한 xmodel SHA, 가중치, 보정 목록, 전후처리와 ISP 파셜 SHA를 manifest에 고정한다. 동일 detector를 Normal과 Lowlight에 공통 적용한다. 테스트를 학습·보정·임계값 선택·최적 체크포인트 선택에 사용하지 않는다. 새 결과를 보고 튜닝하면 해당 holdout은 개발셋으로 재분류하고 최종 시험을 새로 확보한다.

주간·야간·혼합의 mAP50-95가 기본 지표다. DFX는 Normal 및 Lowlight 각각과 더 좋은 고정 방식 모두에 비교한다. 모델/데이터 효과와 ISP 선택 효과를 별도 판정한다. 비열등 허용폭은 아직 합의하지 않았으므로 비열등 통과는 판정하지 않는다.

장면 그룹 수와 프레임 수는 소스 감사 후 확정한다. 서로 독립적인 그룹 수가 부족하면 확증 시험 대신 탐색 결과로 보고한다. 부트스트랩은 장면 그룹 전체를 함께 재표집하고 같은 재표집을 모든 비교에 공유한다. 시간 순서가 있는 DFX 실행은 실제 순서·장면 블록을 유지하고 프레임 재표집 CI와 혼동하지 않는다. 다중 비교 및 기존 시험 재사용을 명시한다.

## 다음 실행 순서
1. Sony 후보의 촬영 세션/장소와 원래 모델 학습 이력을 확인한다. 기존 라벨만으로는 확인할 수 없다.
2. 확인 가능한 새 세션 RAW+라벨 소스를 확보한다. 주야간 각각 독립 그룹을 확보한다.
3. SHA·지각 중복·장면 감사를 통과한 자료만 holdout manifest로 확정한다.
4. 모델/보정/정책을 동결하고 PC 계약 점검 후 보드 평가로 넘어간다. 보드 ISP·DFX 측정은 새 콜드 부팅과 ICAP 선택이 필요하다.
