## 비교 계약과 한계
- YOLO 기준은 기존 배포 xmodel이다. SSD 기준은 기존 가중치를 v2 학습 자료로 재보정하고 SE 고정소수점 위치를 수정한 xmodel이다. 새 SSD도 같은 SE 수정 경로다. 두 모델의 기준선을 같은 종류라고 간주하지 않는다.
- 기존 배포 SSD의 결함 수정 효과와 새 모델의 학습 효과는 별도다. 이 표는 학습 효과 비교용이며 원래 배포 SSD 값은 넣지 않았다.
- 두 검출기는 동일 기존 시험 프레임군을 사용하지만 입력 크기와 전후처리가 다르다. 모델 간 차이를 ISP 효과로 해석하지 않는다.
- 3시드 표준편차는 독립 데이터셋 반복이 아니며 프레임 부트스트랩 신뢰구간과 다르다. 혼합은 주간과 야간 프레임의 합이며 새 독립 표본이 아니다.
- 고정값과 live는 서로 다른 실행에서 얻었다. 동일 프레임의 live ISP RGB는 기준과 해시가 일치했으며 수치는 각 실행의 저장 결과를 그대로 사용한다.
- 야간 모델 개선은 확인됐으나 주간 성능 유지 또는 비열등 통과는 입증하지 못했다. 차이 CI에 0이 포함된다는 이유로 동등이라 하지 않는다.
- 추가 부트스트랩에서 더 좋은 고정 RM 대비 DFX 정확도 우위는 확인되지 않았다. YOLO 혼합에서 Normal 고정 대비 이점과 최선 고정 방식 대비 우위를 구분한다.
- SSD 호스트/보드 검출 잔여 불일치가 있으며 독립 Sony 장면 holdout은 미완료다.
- 순차 하네스 측정이며 처리량이나 프레임 드롭을 평가한 결과가 아니다.
