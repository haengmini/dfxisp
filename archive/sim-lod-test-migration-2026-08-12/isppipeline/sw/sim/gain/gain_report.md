### FAIL 3건 — 신호=3072, 전 채널: 실패가 아니라 포화로 인한 축퇴

신호준위 3072에서 R/G/B 모두 `std_upstream = std_downstream = 0.000`이라
"경로 A가 유의하게 작다"는 판정식(`upstream_significantly_better`)이
엄격 부등식(`0 < 0`)에서 거짓이 되어 FAIL로 찍혔다. 이는 §1 주장이
반증된 사례가 **아니다** — `EXPOSURE_GAIN_Q8=512`(2×)를 곱하면
`(3072−32)×258/256×2.0 ≈ 6137`로 이미 `RAW12_MAX=4095`를 훌쩍 넘어,
두 경로 모두 노이즈 실현과 무관하게 항상 클램프값으로 포화되어 분산이
정확히 0이 되는 **축퇴(degenerate) 케이스**다. 두 경로가 "똑같이
나쁘다"가 아니라 "둘 다 정보가 남지 않는다"는 뜻이므로, 이 3건은 §3.1
판정 기준의 예외로 기록한다.

s=2048에서도 같은 방향의 조짐이 보인다(R: 0.156/0.316, B: 0.091/0.177 —
s=1536 대비 std 자체가 절반 이하로 줄어듦, G는 WB gain이 R/B보다 낮아
(256 < 286/307) 포화가 늦게 시작돼 덜 줄어든다: 0.303/0.438). **이건
`blc_report.md` §2(b)가 이미 플래그해둔 "s≈2048 근처 EXPOSURE_GAIN 포화
아티팩트"와 정확히 같은 현상이고, 그 문서가 예고한 대로 여기(gain.md
쪽)에서 정량적으로 다뤄졌다** — 원인은 BLC 순서가 아니라 stage (3)
gain(2×)이 `RAW12_MAX` 근처에서 만드는 클램프임이 이번 실험으로
확인된다.

## 2. 목표 B — 정수 연산에서도 SNR이 불변인가

**64개 점 중 52개가 ±1.5dB 이내(불변으로 판정), 12개가 이탈.** 이론적
불변성(§2.1)은 **중간 신호준위(48~768 DN 부근)에서는 잘 성립**하지만,
양 극단에서 깨진다 — "깨지는 지점을 정량적으로 기록하는 것 자체가
목표"(§3.2)였던 만큼 두 개의 서로 다른 메커니즘이 드러났다:

**(a) 저신호 쪽(s=16~32): +2~+3.2dB로 SNR이 "개선"되는 것처럼 보임.**
네 gain배수 모두에서 나타나고 배수와 무관하게 크기가 비슷하다 — gain
자체의 효과가 아니라, `gen_binned_samples()`의 입력 생성 단계와 출력
clamp 단계 양쪽에서 걸리는 **0-바닥 클리핑**이 평균보다 분산을 더 크게
깎아내려 SNR 추정치를 부풀리는 censoring 편향이다(`blc.md`가 이미 문서화한
"클리핑은 평균보다 분산을 비대칭적으로 줄인다"는 Jensen 부등식 효과와
같은 계열). 실제 정보 이득이 아니라 **측정 아티팩트**로 해석해야 한다.

**(b) 고신호×고gain 쪽(2.0×/4.0×의 s≥1024~2048): −∞dB로 완전 붕괴.**
`std_out=0`(전수 포화, `clip_rate` 100%)이 되어 SNR 자체가 정의되지
않는다 — §1의 EXPOSURE_GAIN 클램프 붕괴가 임의 gain배수에서도 재현된다.
2.0×는 s=2048부터(부분 포화 48.6% → s=3072 100%), 4.0×는 s=1024부터
가장 먼저 무너진다(부분 48.4% → s≥1536 100%) — gain이 클수록 같은
클램프 경계(4095)에 더 낮은 신호준위에서 도달하므로 예상된 순서다.

| gain배수 | 첫 이탈 신호준위 | 첫 완전붕괴(clip_rate=100%) |
|---|---:|---:|
| 0.5× | 16 (+2.52dB) | 없음(스윕 범위 내 미도달) |
| 1.0× | 16 (+3.00dB) | 없음 |
| 2.0× | 16 (+2.83dB, 저신호) / 2048 (+4.44dB, 클램프 시작) | 3072 |
| 4.0× | 16 (+3.19dB, 저신호) / 1024 (+4.50dB, 클램프 시작) | 1536 |

원자료: `gain_goalB_results.csv`, 그림: `gain_goalB_snr_invariance.png`
(완전붕괴 지점은 `-inf`를 그대로 그릴 수 없어 바닥에 역삼각형으로 표시).

## 3. 목표 C — gain 융합이 분리 적용과 수치적으로 동일한가

**완전 일치 — 0~4095 전 구간, 3채널 모두 차이 없음.**

| 채널 | 12-bit 도메인 차이 | 8-bit(>>4 이후) 차이 |
|---|---|---|
| R | 0/4096, max 0 LSB | 0/4096, max 0 LSB |
| G | 0/4096, max 0 LSB | 0/4096, max 0 LSB |
| B | 0/4096, max 0 LSB | 0/4096, max 0 LSB |

`gain.md` §2.3이 "별도로 확인된 적이 없다"고 남겨뒀던 질문에 확정적인
답이 나왔다 — 융합(`gain_q8 = (EXPOSURE_GAIN_Q8*wb_q8)>>8`, 반올림 1회)과
분리 적용(반올림 2회) 사이에 반올림 오차가 **전혀 없다**. `EXPOSURE_GAIN_Q8=512`가
정확히 2의 거듭제곱(2.0×)이라 `>>8` 절단에서 나머지가 생기지 않는 특수
케이스이기 때문으로 보인다 — 이 결과를 "융합은 항상 무손실"로 일반화하지
말 것(§4 한계 참고). 원자료: `gain_goalC_results.csv`, 그림:
`gain_goalC_fusion_diff.png`(예상대로 평탄한 0선).

## 4. 알려진 한계 (실행 후 추가)

- 목표 C의 "완전 일치"는 `EXPOSURE_GAIN_Q8=512`가 정확히 256의 2배(2.0×,
  `>>8` 절단에서 나머지 0)라는 이 배포값의 특수성 때문일 가능성이 높다.
  `EXPOSURE_GAIN_Q8`이 2의 거듭제곱이 아닌 값으로 바뀌면 재검증이
  필요하다 — gain.md §4가 이미 "회귀 테스트 성격"이라고 명시한 대로다.
- 목표 A의 s=3072 축퇴 케이스와 목표 B의 고신호×고gain 붕괴는 같은
  근본 원인(EXPOSURE_GAIN 2×가 `RAW12_MAX` 근처에서 만드는 클램프)의
  서로 다른 증상이다 — 이 문서의 범위(stage 3 자체의 수치적 성질)를
  벗어나는 질문(예: "클램프 자체를 완화해야 하는가")은 다루지 않는다.
- 목표 B의 저신호 쪽 "+SNR" 편차는 censoring 아티팩트로 해석했지만,
  `blc.md`처럼 별도로 편향(bias)만 격리해 측정한 것은 아니다 — 이
  해석의 정량적 뒷받침이 필요하면 `blc_sim.py`의 방법론(§3.3 CI 기반
  판정)을 여기 신호구간에 적용하는 후속 작업으로 남겨둔다.
- `gain.md` §4가 명시한 한계(목표 A/B의 통계적 유의차가 검출 mAP로
  자동 이어지지 않음)는 그대로 적용된다 — 이 결과는 물리/수치 수준의
  검증이며, mAP 확인 전까지 "배치를 바꿔야 한다"는 결론을 내리지 않는다.

## 5. 결론

1. **목표 A 확인**: 업스트림(넓은 비트폭) 배치가 다운스트림보다 양자화
   손실이 유의하게 작다(평균 2.3배) — §1 ① 주장 지지. 유일한 예외(s=3072)는
   반증이 아니라 두 경로가 동시에 포화되는 축퇴 케이스.
2. **목표 B 부분 확인**: SNR 불변성은 중간 신호준위에서 성립하지만
   저신호(censoring)와 고신호×고gain(클램프 포화) 양 극단에서 깨진다 —
   후자는 `blc_report.md`가 예고한 s≈2048 근처 이상치의 원인을
   정량적으로 설명한다.
3. **목표 C 확인(강한 형태로)**: 융합과 분리 적용이 완전히 일치한다 —
   "반올림 오차 유무 미확인"이었던 §2.3의 공백이 "오차 없음(현재 상수
   기준)"으로 채워졌다.
